# 📱 Ionic Program App — Setup Guide

## Project Structure

```
ionic-program-app/
├── src/
│   ├── app/
│   │   ├── models/
│   │   │   └── program.model.ts        ← Mock data + TypeScript interfaces
│   │   ├── pages/
│   │   │   ├── search/
│   │   │   │   ├── search.page.html    ← Search UI
│   │   │   │   ├── search.page.ts      ← Search logic
│   │   │   │   ├── search.page.scss    ← Search styles
│   │   │   │   └── search.module.ts
│   │   │   └── detail/
│   │   │       ├── detail.page.html    ← Detail UI
│   │   │       ├── detail.page.ts      ← Detail logic
│   │   │       ├── detail.page.scss    ← Detail styles
│   │   │       └── detail.module.ts
│   │   ├── components/
│   │   │   └── filter-modal/
│   │   │       ├── filter-modal.component.html  ← Filter popup UI
│   │   │       ├── filter-modal.component.ts    ← Filter logic
│   │   │       ├── filter-modal.component.scss  ← Filter styles
│   │   │       └── filter-modal.module.ts
│   │   ├── app.component.ts
│   │   ├── app.module.ts
│   │   └── app-routing.module.ts       ← Routes: /search and /detail/:id
│   ├── global.scss                     ← Global Ionic overrides
│   └── index.html                      ← (generated by Ionic CLI)
└── package.json
```

---

## Step 1 — Install Ionic CLI

```bash
npm install -g @ionic/cli
```

---

## Step 2 — Create a New Ionic Project

```bash
ionic start ionic-program-app blank --type=angular
cd ionic-program-app
```

---

## Step 3 — Copy Your Files

Replace/create the following files with the ones provided:

| File | Action |
|---|---|
| `src/app/app.module.ts` | Replace |
| `src/app/app-routing.module.ts` | Replace |
| `src/app/app.component.ts` | Replace |
| `src/global.scss` | Replace |
| `src/app/models/program.model.ts` | Create new |
| `src/app/pages/search/` (all 4 files) | Create new folder + files |
| `src/app/pages/detail/` (all 4 files) | Create new folder + files |
| `src/app/components/filter-modal/` (all 4 files) | Create new folder + files |

---

## Step 4 — Run the App

```bash
ionic serve
```

Opens at **http://localhost:8100**

---

## Step 5 — Build for Production

```bash
ionic build --prod
```

## Features Implemented

### Search Page
- ✅ Program cards matching Figma design exactly
- ✅ University logo overlay on card image
- ✅ "Official Partner" badge
- ✅ Program metadata (country, level, attendance, duration, language)
- ✅ Price display with share + favorite actions
- ✅ Sort modal (relevance, price, views)
- ✅ Filter modal (tags, level, attendance, country)
- ✅ Active filter chips with remove button
- ✅ Search dropdown to change subject
- ✅ Navigation to detail page on card tap

### Detail Page
- ✅ Full-bleed hero image with floating nav buttons
- ✅ Program breakdown grid (duration, level, fee, attendance)
- ✅ Collapsible description, requirements, structure sections
- ✅ Fees breakdown grid
- ✅ Extra info (campus, intake, language)
- ✅ Sticky bottom bar with Back + Apply Now buttons
- ✅ Favorite toggle
- ✅ Share functionality

- ✅ Level radio buttons
- ✅ Attendance radio buttons
- ✅ Country radio buttons
- ✅ Reset all / Apply filters buttons
- ✅ Active filter count badge
